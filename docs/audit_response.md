# Response to the audit (`audit_findings.md`)

The audit itself is kept unchanged. This file records, per finding, what was done and where, in the order the
authors chose ("merge and fix in order", 17 Oct 2026). `python3 tools/check_all.py` is re-run after every item.

| Finding | Status | What changed |
|---|---|---|
| P0.1 stale Fig. 1 output paths | Fixed | `fig1/code/fig1_paths.py` holds the canonical label paths (`full_field_labels/cellpose_sam_labels.tif`, `threshold_labels.tif`); every producer and consumer imports them. Producers write zlib-compressed TIFFs as stored, and `classical_seg.py` re-run in a copy of `fig1/source_data` reproduces every file byte for byte. |
| P0.2 `make check` is not raw-to-figure | Fixed | `make check` is now described as the fast check. `make full` (`tools/check_full.py`) deletes the Fig. 1–2 source data in a copy, regenerates it from `data/raw` in dependency order with an explicit inventory (an unlisted file or a missing input fails), compares every file, and rebuilds both figures byte-identical. It reports the 33 files it does not regenerate and why (Cellpose and SQUIRREL outputs behind `--with-models` / `--with-squirrel`; recovered-inline or unrecovered crops; logs and unused files). `f1_scores.py` is now the single writer of `A_scores.json`; producers write zlib TIFFs as stored. |

Fig. 1 SVG and PDF rebuilt (PDF by `tools/svg_to_pdf.py`). Neither field 104 nor field 209 was in the custom StarDist training set (confirmed by the authors, 17 Oct 2026). |
