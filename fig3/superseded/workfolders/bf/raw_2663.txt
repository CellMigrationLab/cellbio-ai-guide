**What I see and assumed**
- This is a brightfield (phase-like) image of a faint, flat, adherent monolayer.
- On top of it sit many round, refractile cells with a dark rim and a bright halo. They are roughly 25-35 px across, and many touch in clusters of 2-5.
- I assumed these round cells are the cancer cells.
- If the flat cells in the background are the cancer cells instead, say so, because that needs a different approach.
- There is also debris: small dark speckles and black clumps, plus a few saturated bright blobs, for example near (x=900, y=230) and (x=985, y=420).

**How the script works**
1. It flattens the background and computes local standard deviation. The round cells are high in this texture signal and the flat monolayer is low.
2. It thresholds with Otsu, fills holes, and removes small objects, which drops most debris.
3. It splits touching cells with a distance-transform watershed.
4. It filters the resulting objects by size and solidity.

```python
import numpy as np
import tifffile
from scipy import ndimage as ndi
from skimage import filters, morphology, measure, segmentation, feature

# ---- parameters to tune (pixels, for a ~1024x1024 image) ----
TEXTURE_SIGMA = 3      # scale of local-contrast window
MIN_AREA      = 250    # smaller objects = debris
MAX_AREA      = 2500   # larger objects = merged clumps / artifacts
MIN_SOLIDITY  = 0.85   # rejects ragged debris clumps
MIN_DISTANCE  = 9      # min spacing between cell centres for splitting

# ---- load (take first plane/channel if multi-dimensional) ----
img = tifffile.imread("bf.tif")
while img.ndim > 2:
    img = img[0]
img = img.astype(np.float32)
img = (img - img.min()) / (img.max() - img.min() + 1e-8)

# ---- flatten uneven illumination ----
img = img - filters.gaussian(img, sigma=50)

# ---- local standard deviation: high on round refractile cells, low on monolayer ----
m  = filters.gaussian(img, sigma=TEXTURE_SIGMA)
m2 = filters.gaussian(img**2, sigma=TEXTURE_SIGMA)
texture = np.sqrt(np.clip(m2 - m**2, 0, None))

# ---- foreground mask ----
mask = texture > filters.threshold_otsu(texture)
mask = morphology.binary_closing(mask, morphology.disk(3))
mask = ndi.binary_fill_holes(mask)
mask = morphology.binary_opening(mask, morphology.disk(3))
mask = morphology.remove_small_objects(mask, MIN_AREA)

# ---- split touching cells with a distance-transform watershed ----
dist = ndi.distance_transform_edt(mask)
dist = filters.gaussian(dist, sigma=1.5)
peaks = feature.peak_local_max(dist, min_distance=MIN_DISTANCE,
                               labels=measure.label(mask), exclude_border=False)
markers = np.zeros(mask.shape, dtype=np.int32)
markers[tuple(peaks.T)] = np.arange(1, len(peaks) + 1)
labels = segmentation.watershed(-dist, markers, mask=mask)

# ---- filter by size and shape, then relabel ----
out = np.zeros_like(labels, dtype=np.uint16)
k = 0
for r in measure.regionprops(labels):
    if MIN_AREA <= r.area <= MAX_AREA and r.solidity >= MIN_SOLIDITY:
        k += 1
        out[labels == r.label] = k

tifffile.imwrite("labels.tif", out)
print(f"Saved labels.tif with {k} cells")
```

**Things to check and tune**
- **Overlay first.** Overlay `labels.tif` on `bf.tif` (napari or Fiji) before trusting any counts.
- **Merged clusters.** If touching cells stay merged, lower `MIN_DISTANCE` (try 6-7). If single cells get cut in two, raise it.
- **Faint cells missed.** Use a lower threshold than Otsu, for example `0.7 * threshold_otsu(texture)`.
- **Debris counted as cells.** Raise `MIN_AREA` or `MIN_SOLIDITY`.
- **Bright saturated blobs.** The glare blobs may be picked up as cells. Remove them with an intensity cap or by hand.
- **Pixel size.** The size limits assume cells about 30 px across. If your image is scaled differently, change `MIN_AREA` and `MAX_AREA`.

**Alternative.** A pretrained model such as Cellpose (`cyto3` or `cpsam`, diameter about 30) usually splits clusters better on brightfield images like this one. You could use it if the classical result isn't good enough. I can write that version too.
