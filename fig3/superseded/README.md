# Earlier Figure 3 experiments

These runs were kept so that changes to the experimental design can be traced. They are **not** part of the current Figure 3 study. The current plan is [protocol v2](../PROTOCOL_V2.md).

The [runs](runs/) folder contains earlier conversations (indexed in [runs_index.csv](../runs_index.csv)); [workfolders](workfolders/) contains their saved working files; and [figure_builders](figure_builders/) contains earlier figure layouts.

| Earlier experiment | Why it was replaced |
|---|---|
| Counting crops with Opus, Sonnet and Haiku; full-field counts | Changed to one model, full-field images and three tasks. |
| Neutral versus leading questions | Removed from the figure; the manuscript discusses the issue. |
| First code/advice prompts, sandboxed agent and optimisation trap | The single-task design and optimisation setting were not suitable. |
| Brightfield cancer-cell runs | Replaced by the two-target and later three-task designs. |
| Earlier specific code prompts | Replaced by the Box 1 prompt. |
| Box 1 v1 | Prompt wording changed; subsequent runs used v2. |
| Interrupted annotation-assisted agents | Sessions were restarted and repeated from clean folders. |

These records document what was tried, not results that should be pooled with the current study.
