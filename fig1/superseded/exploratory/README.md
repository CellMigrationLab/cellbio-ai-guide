# Exploratory Figure 1 scripts (not part of the figure)

Explorations for earlier versions of Figure 1, kept for the record. They are not run by `make check` or `make full`,
some duplicate logic now in `common/` (matching, junction conversion, pix2pix alignment) or follow an older design,
and some wrote into `source_data/`. Do not run them to regenerate figure inputs; the producers are in `fig1/code/`
(see `fig1/README.md`).
